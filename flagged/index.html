The detail, item by item

Why each one matters, and what this build did about it.

high F01

The three submitted short links are not confirmed as enrolled Associates Special Links

Why it matters. Amazon's Program Policies require Special Links to carry the Associate tag as a URL parameter, and require the Associate to keep track of which link formats are permitted. Publishing links whose tracking is unconfirmed risks earning nothing while looking like it works.

What this build did. Every outbound link on this site therefore uses a freshly built tagged URL (https://www.amazon.com/dp/ASIN?tag=shopnow047c-20) rather than the short token, and is marked Sponsored.

Recorded status: needs review

medium F03

The air-fryer working titles in the brief have no matching products

Why it matters. Publishing four air-fryer guides against a wallpaper tool and two cabinet racks would be a content-to-product mismatch, and the brief itself described those titles as working titles, not verified demand.

What this build did. Four replacement guides were written in the same question-shaped format against the categories that do have verified products. The air-fryer titles remain unpublished in the live edition. The earlier edition's four air-fryer guides are preserved at /archive/practical-home/ with noindex, kept for the record rather than promoted.

Recorded status: needs review

medium F04

Search Console is not verified: no verification token was available

Why it matters. Without Search Console, the site cannot report which queries it appears for, so topic selection cannot be driven by measured queries.

What this build did. The build already supports the token: it emits the meta tag on every page as soon as the value is supplied. sitemap.xml and feed.xml are ready to submit.

Recorded status: needs review

The analytics endpoint is not deployed, so the five events stay in the browser

Why it matters. Instrumentation without a sink produces no reports, so the ledger stays empty.

What this build did. No data leaves the browser until an endpoint is configured. Nothing is simulated, estimated or back-filled.
