# The Considered Home

A static GitHub Pages publication with question-led kitchen buying guides and an evidence register. No build dependencies are required. Serve the repository root with `python3 -m http.server 8000` for local review.

The supplied Amazon short links and tracking ID are unverified. Product data, live analytics, conversion tracking, AI services and Amazon account integration are not implemented. Review the site's Flagged for Review and Executive Summary pages before promoting products. GitHub Pages is static and cannot itself host an analytics ingestion endpoint.
