Measurement

What is measured, and what is not

Five events, defined in advance, recorded in the visitor’s browser, and sent nowhere until an endpoint exists. This page is the honest status of that, not a dashboard of numbers that do not exist.

Current status: instrumented, not collecting

Endpoint configured: none. With no endpoint, no event leaves the browser: the five events accumulate in this browser’s local storage and appear in the table at the bottom of this page. That is a real limitation, recorded as F05, not a placeholder pretending to be analytics.

The five events

Event contract for site_id: diyhome1. Payload fields are the complete list sent for each event.

Privacy rules, enforced in code

  • No cookies are set, and none are read.
  • No third-party scripts, fonts, images or pixels are loaded. The page makes no request off this domain except when a visitor clicks a Sponsored link.
  • The session identifier lives in sessionStorage and dies with the tab.
  • The referrer is reduced to a class (none, internal, search, external); the full URL is never stored.
  • No IP address, user agent or location is recorded by the client. The collector is specified to discard the connecting IP.
  • If the browser sets Do Not Track or Global Privacy Control, no event is recorded at all.
  • The local queue is capped at 200 events and can be cleared or exported below.

To turn collection on

  1. Deploy the collector in worker/collect.js (Cloudflare Worker) or any endpoint that accepts the JSON contract above.
  2. Put that URL in data/site.json under analytics.endpoint, then run node scripts/build.mjs. The value is written into assets/js/config.js at build time.
  3. Reload the site: events are sent with navigator.sendBeacon, so they survive the outbound click.
  4. Add a dated row to the campaign ledger once a first-party report exists. Until then the ledger stays empty.
