How this site verifies a product

The rule is simple and it is enforced by a script: every published value must trace to an official source, and anything that cannot is left blank and listed on the flagged page.

The five steps

  1. Resolve the link. Each supplied link is fetched once, and the final URL and page title are recorded. The redirect target is stored in its own field, never merged with the intended ASIN.
  2. Read the listing. The listing title and category breadcrumb are copied verbatim, with the retrieval date. Those are the only product attributes this site publishes.
  3. Record the source. Every row carries an ID that maps to a URL in the source register.
  4. Refuse the rest. Prices, star ratings, review counts, availability, commission rates and images are not published, because this site has no sanctioned route to them.
  5. Flag the gap. Anything unverified is written up at Flagged for review with what it needs.

What “verified” means here, and what it does not

Verified means: on the date shown, a fetch returned a live listing page whose title and breadcrumb matched what is published here. That is all it means. It does not mean the product is good, that the price is what you will pay, or that the listing will still exist next month.

Not verified means the value is blank, or the sentence says so explicitly. Inference is not used to fill a gap. If a brand does not appear in a listing title, the brand column stays empty.

Why the shop has no prices or star ratings

Amazon’s Associates Program Policies allow a site to show prices and availability only if Amazon serves the link containing that data, or if the data comes from the Creators API or PA API. Customer reviews and star ratings are restricted the same way. This site has neither an API licence nor an Amazon-served widget, so those numbers are omitted. S01

There is a second reason, and it is editorial rather than legal: a price scraped into a static page is wrong the moment it is built. A shop that shows a wrong price is worse than one that sends you to the live listing.

Why nothing here claims experience

FTC guidance says you cannot talk about your experience with a product you have not tried. No product on this site has been bought or used, so the copy describes the listing and the buying decision, and product pages say so on the page. S03

Automation, and the rule that governs it

Amazon’s current program terms add explicit Agent Terms: software that accesses program content must identify itself in its user agent as Agent/[agent name], must not conceal that it is automated, and must not circumvent measures meant to distinguish computers from humans. S01

The verification fetches for this issue did not set that user agent, and no Associates credential was used. That is recorded as irregularity F13 rather than quietly fixed, because it changes what an automated build of this site is allowed to do next.

What this site is not

It is not a review site, and it does not rank products. With one verified product per category, a ranking would be an invention. It is also not affiliated with Amazon beyond participation in the Associates program.
