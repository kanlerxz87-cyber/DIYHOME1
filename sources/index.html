Source register

Every source used on this site, what it supports, when it was retrieved, and whether it could actually be read. Two entries are marked as unreadable on purpose: pretending otherwise is how a register becomes decoration.

Reading the badges

Read means the page was retrieved and the quoted text was read on it. Secondary means the page is not first-party documentation and is used only to explain a gap. No access means the page exists but sits behind a sign-in wall, so nothing was cited from it.

Each source below was retrieved and read in this session unless marked otherwise. 'verified' means the text quoted in the site was read on that page. 'secondary' means the page is not first-party documentation and is used only to explain a flagged gap. 'unavailable' means the source exists but could not be retrieved without credentials.
